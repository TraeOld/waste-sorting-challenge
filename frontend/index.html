Waste Sorting Challenge

Learn recycling through play.

How to Play

  1. Look at the waste item on the card.
  2. Choose the bin you think it belongs to.
  3. A correct answer gives 10 points. A wrong answer costs 1 heart.
  4. You start with 3 hearts. The game ends when they run out.

The Four Bins

    The game uses a simplified four-category waste classification system for educational purposes. Always follow your local collection rules in real life.
